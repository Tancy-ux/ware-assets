# ware-assets

Ware Innovations' team site (brand assets, FAQs, the Chats page) and the
"Ware concierge" AI chat on www.wareinnovations.com, backed by Supabase.

- Team site: https://tancy-ux.github.io/ware-assets/
- **Everything it does, how to run, change and deploy it:
  [docs/GUIDE.md](docs/GUIDE.md)**
- The Shopify chat widget: [widget/README.md](widget/README.md)

```
npm install
npm run dev           # team site locally
npm run build:widget  # the store chat script
```
